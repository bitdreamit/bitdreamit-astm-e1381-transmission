RECENT FIX HISTORY (newest first)
============================================================

v1.3.3 (this release)
  - Redesigned the ASTM E1381 settings dialog to use Mirth Connect's
    private UI component library (MirthTextField, MirthCheckBox,
    MirthComboBox) - the same components Mirth's built-in MLLP
    transmission mode uses. The dialog now picks up Mirth's L&F,
    tab-order, and validation styling automatically.
  - Fixed the "Save button doesn't save" bug. Root cause: the v1.3.2
    dialog never loaded its fields from the Properties object on open
    (it showed hardcoded defaults), and on OK the provider wrote the
    dialog values into a FRESH Properties object instead of writing
    back to the Properties reference Mirth had passed in via
    setProperties(). Fix: the dialog now takes the Properties object
    in its constructor, calls loadFromProperties() on open, and writes
    the field values back INTO the SAME Properties object on OK.
  - Added input validation with red-border error highlighting on every
    field. The dialog stays open until all fields are valid or the
    user clicks Cancel.
  - OK button is now the default button (Enter activates it).
  - Extended checkProperties() and resetInvalidProperties() to cover
    all 7 numeric fields (responseTimeout, maxTransferAttempts,
    checksumByteLength were missing in v1.3.2).

v1.3.2
  - Fixed 4 ASTM E1381 protocol state-machine bugs in
    ASTME1381StreamHandler.java:
    (1) frame-number wrap 1,2,...,7,0,1,... now correct (the
        old code skipped frame 0 and NAK-looped every message
        with >= 8 frames);
    (2) EOT during session establishment no longer aborts the
        receiver - it returns to IDLE and waits for the next
        ENQ (the old code died after every successful transfer);
    (3) frameStartTime is now reset on every NAK so the retried
        frame gets a fresh timeout window;
    (4) all poll loops honor Thread.interrupted() and convert
        InterruptedException to IOException so stopping the
        channel breaks out of blocking ENQ waits immediately.
  - Added patches/serialsourceconnector-astm-no-data-fix.patch
    (companion patch for the separate bitdreamit-mirth-labextensions
    serial-connector module).

v1.2.6
  - Removed ASTME1381ClientProvider from <clientClasses>. It
    extends TransmissionModeClientProvider (NOT ClientPlugin), so
    Mirth's Administrator UI failed silently when trying to load
    it as a ClientPlugin.
  - Improved settings panel layout to match the MLLM reference.

v1.2.5
  - Removed ASTME1381TransmissionModeProperties from serverClasses
    and clientClasses (caused ClassCastException at server startup).

v1.2.4
  - Settings panel now extends JPanel (not AbstractSettingsPanel),
    uses standard Swing components + GridBagLayout (not MigLayout).

v1.2.3
  - Fixed XmlPullParserException (XML comments had illegal dashes).

v1.2.2
  - Fixed "duplicate entry: com/" ZipException in build.sh on JDK 8.

v1.2.1
  - Added log4j-1.2-api-2.17.2.jar to build.sh SERVER_CP.

v1.1.9
  - Rewrote plugin.xml to use the actual Mirth 4.5.2 format.

(Earlier versions: see CHANGELOG.md)

============================================================
BUILD
============================================================

1. Extract this zip:
     unzip bitdreamit-astm-e1381-transmission.zip
     cd bitdreamit-astm-e1381-transmission

2. Provide Mirth Connect 4.5+ jars at ../mirth-libs/ (see above).

3. Build using one of:

   a) IntelliJ IDEA Build Artifacts:
        File -> Open -> Build -> Rebuild Project ->
        Build -> Build Artifacts... -> All Artifacts -> Build.

   b) Shell script:
        cd distribution
        ./build.sh            build all JARs + XML to ../out/
        ./build.sh clean      remove ../out/ (note: SPACE before "clean")
        ./build.sh test       build + run JUnit tests
        ./build.sh rebuild    clean + build

   c) Deploy helper:
        cd distribution
        ./deploy.sh             build + assemble ../out/<ext-name>/
        ./deploy.sh zip         also produce ../out/<ext-name>.zip
        ./deploy.sh install     also copy to $MIRTH_HOME/extensions/

   d) Maven:
        mvn -Dmirth.libs=$HOME/mirth-libs clean package

4. Output (5 production files in ../out/):
     bitdreamit-astm-e1381-transmission-shared.jar
     bitdreamit-astm-e1381-transmission-server.jar
     bitdreamit-astm-e1381-transmission-client.jar
     plugin.xml
     transmissionmode.xml

============================================================
DEPLOY TO MIRTH CONNECT
============================================================

A) Install via the Mirth Administrator UI Extension Manager:
   - Build + assemble via ./deploy.sh zip
   - Mirth Administrator: Extensions -> Extension Manager -> Install

B) Manual file copy:
     MIRTH_HOME=/opt/mirth-connect
     EXT_DIR=$MIRTH_HOME/extensions/bitdreamit-astm-e1381-transmission

     sudo systemctl stop mirth-connect
     [ -d "$EXT_DIR.bak" ] && rm -rf "$EXT_DIR.bak"
     [ -d "$EXT_DIR" ] && mv "$EXT_DIR" "$EXT_DIR.bak"
     mkdir -p "$EXT_DIR"
     cp out/bitdreamit-astm-e1381-transmission-shared.jar  "$EXT_DIR/"
     cp out/bitdreamit-astm-e1381-transmission-server.jar "$EXT_DIR/"
     cp out/bitdreamit-astm-e1381-transmission-client.jar "$EXT_DIR/"
     cp plugin.xml             "$EXT_DIR/"
     cp transmissionmode.xml   "$EXT_DIR/"
     sudo systemctl start mirth-connect

After Mirth restarts, the "ASTM E1381" transmission mode appears in
the channel editor under TCP Listener / TCP Sender -> Transmission Mode.
