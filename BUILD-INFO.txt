RECENT FIX HISTORY (newest first)
============================================================

v1.2.2 (this release)
  - Fixed "java.util.zip.ZipException: duplicate entry: com/" in
    build.sh. The server and client JAR packaging rules used two
    -C options to merge shared + module-specific class directories.
    JDK 8's "jar" tool rejects duplicate directory entries (com/),
    while JDK 9+ merges them automatically. Fix: use a staging
    directory - copy shared + module classes into a single dir,
    then package from that dir with one -C option.

v1.2.1
  - Added log4j-1.2-api-2.17.2.jar to build.sh SERVER_CP. Without
    it, the server module fails to compile with
    "package org.apache.log4j does not exist" (org.apache.log4j.Logger
    is a Log4j 1.x -> 2.x bridge class shipped in that JAR).

v1.2.0
  - Added ASTME1381TransmissionModeProperties to <serverClasses>
    AND <clientClasses> in plugin.xml so XStream allows deserialization.

v1.1.9
  - Rewrote plugin.xml to use the actual Mirth 4.5.2 format
    (<string> elements + top-level <library>).

v1.1.8
  - Changed <serverClass class="..."> -> <serverClass name="...">
    (partial fix, properly fixed in v1.1.9).

v1.1.7
  - Consolidated to single plugin.xml. Added deploy.sh helper.

v1.1.6
  - Removed send() from ASTME1381ClientProvider.

v1.1.5
  - Added miglayout-core-4.2.jar. Implemented abstract methods.

v1.1.4
  - Added getSampleLabel() override.

v1.1.3
  - Fixed wrong base class names. Deleted ASTME1381ServerProvider.

v1.1.2
  - Removed phantom @Override on getPropertyDescriptors()/setProperties().

v1.1.1

v1.1.0

v1.0.0 (original release)

============================================================
BUILD
============================================================

1. Extract this zip:
     unzip bitdreamit-astm-e1381-transmission.zip
     cd bitdreamit-astm-e1381-transmission

2. Provide Mirth Connect 4.5+ jars at ../mirth-libs/ (see above).

3. Build using one of:

   a) IntelliJ IDEA Build Artifacts:
        File -> Open -> Build -> Rebuild Project ->
        Build -> Build Artifacts... -> All Artifacts -> Build.

   b) Shell script:
        cd distribution
        ./build.sh            # build all JARs + XML to ../out/
        ./build.sh clean      # remove ../out/ (note: SPACE before "clean")
        ./build.sh test       # build + run JUnit tests
        ./build.sh rebuild    # clean + build

   c) Deploy helper:
        cd distribution
        ./deploy.sh             # build + assemble ../out/<ext-name>/
        ./deploy.sh zip         # also produce ../out/<ext-name>.zip
        ./deploy.sh install     # also copy to $MIRTH_HOME/extensions/

   d) Maven:
        mvn -Dmirth.libs=$HOME/mirth-libs clean package

4. Output (5 production files in ../out/):
     bitdreamit-astm-e1381-transmission-shared.jar
     bitdreamit-astm-e1381-transmission-server.jar
     bitdreamit-astm-e1381-transmission-client.jar
     plugin.xml
     transmissionmode.xml

============================================================
DEPLOY TO MIRTH CONNECT
============================================================

A) Install via the Mirth Administrator UI's Extension Manager:
   - Build + assemble via `./deploy.sh zip`.
   - Mirth Administrator: Extensions -> Extension Manager -> Install.

B) Manual file copy:
     MIRTH_HOME=/opt/mirth-connect
     EXT_DIR=$MIRTH_HOME/extensions/bitdreamit-astm-e1381-transmission

     sudo systemctl stop mirth-connect
     [ -d "$EXT_DIR.bak" ] && rm -rf "$EXT_DIR.bak"
     [ -d "$EXT_DIR" ] && mv "$EXT_DIR" "$EXT_DIR.bak"
     mkdir -p "$EXT_DIR"
     cp out/bitdreamit-astm-e1381-transmission-shared.jar  "$EXT_DIR/"
     cp out/bitdreamit-astm-e1381-transmission-server.jar "$EXT_DIR/"
     cp out/bitdreamit-astm-e1381-transmission-client.jar "$EXT_DIR/"
     cp plugin.xml             "$EXT_DIR/"
     cp transmissionmode.xml   "$EXT_DIR/"
     sudo systemctl start mirth-connect

After Mirth restarts, the "ASTM E1381" transmission mode appears in
the channel editor under TCP Listener / TCP Sender -> Transmission Mode.
